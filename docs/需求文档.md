# IT部知识共享服务平台 · 需求文档

> 版本：v1.4（2026-11-20，约 1000 个注册读者、约 100 名内容维护者） · 状态：实施口径
> v1.4 变更：查阅端只公开问题记录；工作台改为「按业务系统」组织；业务文档/技术文档登录可见；编辑器三种类型（培训手册作为标签）；成员可限定可见业务系统（数据权限）
> 前身：WMS同步ERP报错知识库（静态单文件版，`workbuddy.link/p/U6JbceEheJuGLi9kBny5Wn`）

## 一、背景与目标

现有知识库为静态单文件架构（数据编译进 HTML、编辑只落浏览器本机、发布靠单人跑脚本），存在四个硬伤：

| # | 问题 | 后果 |
|---|---|---|
| 1 | 数据编译进页面 | 每次更新都要"构建→发布"，内容更新滞后 |
| 2 | 编辑只存访问者本机 | 多人编辑互相不可见，靠导出更新包人肉汇总，会互相覆盖 |
| 3 | 无账号体系 | 不知道谁改了什么，无审计能力 |
| 4 | 内容形态单一 | 只有问答卡，技术手册/业务文档/个人草稿无处安放 |

**目标**：升级为内网 Docker 部署的多用户知识平台——保存即生效、LDAP 统一认证、权限可管、内容可审计，集中维护问题记录、业务文档和技术文档，并为二期钉钉机器人预留接入。

## 二、用户与角色

| 角色 | 来源 | 能力 |
|---|---|---|
| 未登录访客 | 无 | 浏览全部公共空间（查阅/搜索） |
| VIEWER | LDAP 登录后默认 / 本地账号创建时指定 | + 个人区域读写、评论（二期） |
| EDITOR | 管理员授予 / LDAP 域组映射 | + 被授权空间内新建、编辑、发布、上传文件 |
| ADMIN | 指定 | + 用户与角色管理、空间与权限、操作日志、全局配置 |

**账号来源两种，都要支持**：

| 类型 | 认证方式 | 用途 |
|---|---|---|
| LDAP 域账号 | 域账号 + 域密码，首次登录自动建档 | 公司正式员工，域控加人自动可用 |
| 本地账号 | 平台内创建，BCrypt 密码 | 外包/无域账号同事、钉钉机器人 service 账号、应急管理员 |

权限模型：**全局角色 + 空间 ACL + 单篇读取限制**。公开空间内未单篇限制的内容允许匿名阅读；空间 ACL 可绑定 LDAP 域组或用户；敏感单篇可在空间默认范围内进一步收紧到用户或组。系统管理员默认可读并记录受限内容访问审计。个人区域仅本人可见。

## 三、内容模型

**空间（Space）→ 文档（Doc）** 两层。文档按问题记录、业务文档和技术文档区分：

| doc_type | 形态 | 说明 |
|---|---|---|
| `qa` | 问题记录（结构化） | 现有 KB 卡片字段整体迁入：归属系统、问题分类、报错原文、一句话答案、原因、运维语句、步骤、注意、截图、关键词、状态 |
| `req` | 业务文档 | 业务流程、操作手册、培训手册等；正文 MEDIUMTEXT 存库；培训手册用标签区分，不单独设类型 |
| `tech` | 技术文档 | 技术方案、部署配置及排查记录；正文 MEDIUMTEXT 存库 |
| `md` | 旧版 Markdown | 兼容既有未分类文档；新建内容使用明确类型 |

一期内置空间：**问题记录（公开）**、**业务文档（登录可见）**、**技术文档（登录可见）**、个人区域（每人一个，内置）。
业务文档/技术文档的空间可见性为 `INTERNAL`，匿名访客只能看到问题记录；该分区通过启动时的一次性迁移 `content_scope_v1` 落地（`sql/upgrade-2026-11-20-content-scope.sql` 留档）。
后续新增分区只加一行空间记录，不改表不改代码。

**文件（图片/附件）单独一张表 `it_file` 存**：文件元数据按文档和上传人隔离，文件本体落 MinIO 对象存储，文档正文只存引用 URL。内容哈希用于同文档范围内复用，避免不同文档误共享附件权限。

## 四、功能需求

### 4.1 查阅端（对全员开放）

**公开范围只有问题记录**：首页与详情页对未登录访客只展示 `doc_type=qa` 的内容；业务文档、技术文档登录后在「工作台」按业务系统查看。首页结构为：居中头图（问题记录 / 收录系统统计）→ 内容筛选（系统 / 问题分类）→ 结果列表，右侧栏放「最近更新」与「快速开始」（登录后为写记录/个人区域/工作台入口）。

| 编号 | 需求 | 优先级 |
|---|---|---|
| P1-01 | 全文搜索：报错原文/单据号/字段名/标题/正文，多词空格分隔需同时命中 | P0 |
| P1-02 | 两级筛选：① 归属系统（工单/文档归属）→ ② 问题分类，联动计数、切系统自动回落 | P0 |
| P1-03 | 问答卡展示：一句话答案置顶、报错原文、处理步骤、注意事项、截图灯箱放大 | P0 |
| P1-04 | Markdown 文档阅读：渲染 + 自动目录导航 + 代码块高亮 | P0 |
| P1-05 | 分享：单条锚点链接（打开自动定位展开） | P2 |
| P1-06 | 搜索防抖、空结果引导 | P2 |
| P1-07 | **移动端适配（≤768px），仅只读浏览**：不提供 LDAP 登录、不提供个人区域、无任何编辑入口；侧栏筛选改顶部横向 chip + 筛选抽屉；卡片单列；目录收进抽屉；图片灯箱支持双指缩放与左右滑动；触控目标 ≥44px | P0 |
| P1-08 | 移动端只调用公开只读接口（`GET /docs`、`GET /spaces` 公共部分），接口层杜绝写操作 | P0 |
| P1-09 | 管理端不做手机适配，窄屏提示"请使用电脑" | P2 |

### 4.2 登录与个人区域

| 编号 | 需求 | 优先级 |
|---|---|---|
| P2-01 | **双通道登录**：LDAP 域账号（域密码认证，首次登录自动建档，默认 VIEWER）+ 本地账号（平台密码，BCrypt 校验）；登录页可切换，JWT 会话 | P0 |
| P2-02 | 个人区域：仅本人可见的草稿空间，问答卡/文档均可写；页面含「我的草稿」列表与账号/角色/可写入空间说明 | P0 |
| P2-03 | 一键发布：个人区域内容发布到有 EDITOR 权限的公共空间（直接生效，日志留痕） | P0 |
| P2-04 | 本地账号安全：≥8 位含字母数字；ADMIN 重置生成临时密码并强制首次改密；同账号 5 次失败锁 10 分钟 | P0 |
| P2-05 | LDAP 不可用时降级：仅本地账号可登录（可配置），域账号提示稍后重试 | P1 |

### 4.3 管理端（登录后）

**组织方式：按业务系统，而不是按内容类型**。左侧导航为「工作台首页 / 全部问题记录 / 全部业务文档 / 全部技术文档 / 个人区域」（管理员另有「空间与权限 / 成员角色 / 基础数据 / 系统设置」）。工作台首页展示内容统计 + 业务系统卡片（每个系统显示问题记录/业务文档/技术文档数量），点开系统进入该系统的问题记录列表，再按三个类型页签切换；新建时类型和归属系统随当前上下文带入。

| 编号 | 需求 | 优先级 |
|---|---|---|
| P3-00 | **成员管理**：用户列表（域账号/本地账号分列标识）、新建本地账号、分配全局角色、停用/启用、重置密码、查看最近登录时间 | P0 |
| P3-00b | **可见系统（数据权限）**：创建/编辑成员时可限定其可见业务系统；限定后只能查看和维护归属这些系统的问题记录，无系统归属的文档不受限；个人区域草稿不受此约束，ADMIN 不受限 | P0 |
| P3-01 | 卡片/文档管理：列表（编号/标题/归属系统/更新人/时间）、新建、编辑、软删除、上下架 | P0 |
| P3-02 | 问答卡结构化编辑表单（沿用现有 15 字段）；文档用 md-editor-v3 左编右预 | P0 |
| P3-03 | 文件上传：编辑器粘贴/上传 → `/api/files` 落服务器卷并写 `it_file` 表 → 返回内链；图片与附件统一走这一套 | P0 |
| P3-03b | 附件支持：文档可挂 docx/xlsx/pdf/zip 等附件（白名单校验，单文件 ≤20MB），展示原始文件名与大小，点击按原名下载 | P0 |
| P3-04 | 版本快照：每次保存自动插入版本，可回看、可回滚、可 diff | P0 |
| P3-05 | 空间与权限：空间增删改、LDAP 域组映射、成员角色管理 | P0 |
| P3-06 | 操作日志：谁、何时、对哪条、改前改后值；可按人/文档筛选 | P0 |
| P3-07 | 批量导入：md 文件夹/zip 批量导入为文档；qa 卡 JSON 批量导入 | P1 |
| P3-08 | docx 上传自动转 Markdown 导入（poi 转换） | P1 |

## 五、非功能需求

| 类别 | 要求 |
|---|---|
| 规模 | **约 1000 个注册读者、约 100 名内容维护者**；日活与峰值同时在线待上线观察后固化，注册数不代表并发数 |
| 部署 | 公司内网 Docker：单机 compose 起步（nginx + **app ×1** + mysql + **minio**，redis 可选）；app 保持无状态，滚动发布时临时起 ×2，需要时再加副本 |
| 性能 | 使用接近生产的数据量和实测峰值进行压测；列表与搜索 **P95 ≤ 2 秒**、错误率 < 0.1%，其余接口建立延迟基线 |
| 容量 | 上线前盘点文档、版本、附件和日志数据并设置 MySQL / MinIO 容量告警，不预设固定上限 |
| 可用性 | app 健康检查 + 启动即恢复（无状态），单实例重启 1 分钟内可访问；工作时间可用性目标 99.5% |
| 安全 | 所有读写入口统一执行后端鉴权；公开且未单篇限制的内容匿名可读；敏感单篇按用户或 LDAP 组收紧；管理员读取受限内容留痕；文档与附件响应禁止共享缓存 |
| 审计 | 全部写操作进 `it_op_log`，含改前改后值；管理员读取受限文档也记录 |
| 备份 | MySQL 每日全量 dump **+ binlog（RPO ≤ 15 分钟，可按时间点恢复）**；文件走 MinIO 独立备份（若无 MinIO 则卷内文件同备，缺一不可） |
| 移动端 | 查阅端响应式（≤768px 断点），**纯只读**：手机端不登录、无个人区域、无写操作，仅调公开只读接口；管理端仅桌面 |
| 数据迁移 | 旧静态库 25 条问答卡结构与口径（system=工单归属系统）原样迁入；示例卡不迁 |

## 六、验收口径（关键几条）

1. 编辑保存后，任意同事刷新页面立即可见——**不再存在"构建/发布"环节**。
2. 任意一条内容都能回答"谁在什么时候改的、改之前是什么"。
3. LDAP 域组里加人后，该用户对绑定空间自动获得编辑权，无需平台内手工授权。
4. 个人区域内容管理员不可见；发布到公共空间后在日志中留痕。
5. 内网断外网全功能可用（无 CDN/外网依赖，前端资源本地打包）。
6. **压测通过**：用接近生产的数据量和实测峰值并发覆盖搜索、列表、详情、附件及保存；列表和搜索 P95 ≤ 2 秒、错误率 < 0.1%，记录资源与慢查询结果。
7. **文件与实例解耦**：删除并重建 app 容器后，已有图片/附件仍能正常打开（验证文件不依赖容器本地盘）。
8. **公开范围正确**：未登录访问首页/列表/搜索只返回问题记录；直接打开业务文档或技术文档地址返回 403/登录引导。
