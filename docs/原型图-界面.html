A

移动端适配要点（开发照此做）

  • 断点 768px，Vue 侧用 CSS 媒体查询 + 条件渲染共用同一套组件，不另写一套移动页面。
  • 手机端纯只读——不提供登录、不提供个人区域、不出现任何新建/编辑/删除按钮，也不请求需要鉴权的接口。
  • 管理端后台不做手机适配，窄屏提示「请使用电脑」。
  • 文档阅读页在手机上目录收进顶部抽屉，正文单栏全宽。
  • 触控目标 ≥44px，正文字号不小于 12px，辅助信息不小于 10.5px。
  • 图片灯箱必须支持双指缩放与左右滑动，否则报错截图在手机上看不清。
  • 手机端只调 GET 公开接口（/api/docs、/api/spaces 公共部分），从接口层面杜绝误操作。
B

设计口径备忘

  • 未登录可浏览全部公共空间；写操作一律要求登录。
  • 权限按钮显隐只为体验，后端必须二次校验，前端不构成权限边界。
  • 个人区域内容管理员默认不可见，审计例外走操作日志。
  • 全部写操作进日志并生成版本快照，删除为软删除可还原。
  • 二期钉钉机器人收录/推送仅用预留字段与开放 API，不改表结构。
